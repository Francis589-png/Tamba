# Tamba Roadmap

## 0.1 — Foundation
- Lexer, parser, AST, interpreter
- JUSU CLI and REPL
- Source-aware errors
- Tests and CI

## 0.2 — Language
- Collections
- Modules
- Better type errors
- Complete call-stack diagnostics

## 0.3 — Runtime
- Bytecode VM
- Profiling
- Concurrency

## 0.4+ — Native
- Native compiler/JIT
- FFI
- Safe/unsafe memory APIs
- Cross compilation

## Ecosystem
- JUSU package manager and registry
- AI/data, game, web, desktop, Android, macOS, Windows and IoT libraries
- Long-term target: 700+ real, maintained official libraries
